# Overview

As a **Lab Assistant** at Gunadarma University for 2 semesters, I contributed to developing practicum modules for the **Algorithm and Programming** course using Python.

# Responsibilities

- Served as the person-in-charge assistant for weekly practicum sessions
- Assisted the lecturer and lab head in running practicum activities
- Contributed to developing and updating practicum materials
- Maintained laboratory equipment

# What I Contributed

The modules I helped develop cover:

- Basic algorithm concepts (sorting, searching, recursion)
- Basic data structure implementation using Python
- Practice problems and practicum quizzes
- Step-by-step guides for students new to programming

# Impact

These modules were used by hundreds of students each semester. The experience taught me that **writing code others can understand** is just as important as writing code that runs, a principle I still carry today.

# What I Learned

Teaching is the best way to learn. When explaining concepts to students touching programming for the first time, I was forced to truly understand the fundamentals, not just memorize syntax, but grasp *why* things work the way they do.
