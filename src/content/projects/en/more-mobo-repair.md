# Overview

MORE (MoBo Repair) is an Android application for motherboard repair service management, a project born from the MSIB program and the direct predecessor of **BengkelHub** as a multi-tenant web platform.

# The Origin

This project was built with a team during the MSIB program. After graduating, I decided not to simply leave it behind as a memory. I rebuilt the concept solo into a more mature web platform (BengkelHub), proving that I could take an idea from start to production on my own.

# Process

Before writing a single line of code, the team conducted **7 days of user research**: interviews with repair shop owners, observation of their workflows, and identification of key pain points. The findings became the foundation for every design and feature decision.

Usability testing was conducted using a structured methodology to validate prototypes before development began.

# Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **IDE**: Android Studio
- **Design**: Figma (wireframe to prototype to handoff)

# Key Features

- Service order management (create, update, track status)
- Customer data and service history
- Clean, intuitive UI for technicians in the field
- Design validated through usability testing

# What I Learned

This project taught me that **research comes before code**. The seven days of user research that felt "long" actually saved a significant amount of revision time during development. It was also my first experience working in a cross-functional team with designers and a project manager.
