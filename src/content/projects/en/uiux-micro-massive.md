# Overview

During my internship at **Kinema Systrans Multimedia**, I served as both Android Developer and UI/UX Designer for two enterprise projects: **Micro** and **Massive**. I also acted as the coordinator between the design and development teams.

# Role

This hybrid position required me to think in two modes simultaneously: like a designer when building prototypes, and like an engineer when implementing them. Cross-team coordination was my primary responsibility.

# Process

The design workflow I followed:

1. **Discovery**: kickoff meeting, gathering requirements from stakeholders
2. **Research**: user interviews and competitive analysis
3. **Wireframing**: low-fidelity wireframes in Figma
4. **Prototyping**: high-fidelity interactive prototype
5. **Testing**: usability testing using **Maze** (remote, unmoderated)
6. **Handoff**: design specs and assets for developers

# Tools

- **Figma**: design, prototyping, component library, developer handoff
- **Maze**: remote usability testing and analytics
- **Android Studio + Jetpack Compose**: UI implementation on the Android side

# Key Deliverables

- Design system with reusable components
- Interactive prototype validated through usability testing
- Android UI implementation using Jetpack Compose
- Usability testing report with actionable insights

# What I Learned

I learned that **good design must be implementable**, and good implementation must respect the intent of the design. The gap between the two is often a source of conflict in teams, and this experience gave me the perspective to bridge both sides.
