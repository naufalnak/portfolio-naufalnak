# Overview

Selama magang di **Kinema Systrans Multimedia**, saya berperan sebagai Android Developer sekaligus UI/UX Designer untuk dua project enterprise: **Micro** dan **Massive**. Saya juga bertugas sebagai koordinator antara tim desainer dan developer.

# Role

Posisi hybrid ini mengharuskan saya memahami dua dunia sekaligus  berpikir seperti desainer saat membuat prototype, lalu berpikir seperti engineer saat mengimplementasikannya. Koordinasi antar tim menjadi tanggung jawab utama saya.

# Process

Workflow desain yang saya jalani:

1. **Discovery**  kickoff meeting, gathering requirements dari stakeholder
2. **Research**  user interview dan competitive analysis
3. **Wireframing**  low-fidelity wireframe di Figma
4. **Prototyping**  high-fidelity interactive prototype
5. **Testing**  usability testing menggunakan **Maze** (remote, unmoderated)
6. **Handoff**  design specs dan assets untuk developer

# Tools

- **Figma**  design, prototyping, component library, developer handoff
- **Maze**  remote usability testing dan analytics
- **Android Studio + Jetpack Compose**  implementasi UI di sisi Android

# Key Deliverables

- Design system dengan komponen yang reusable
- Interactive prototype yang divalidasi melalui usability testing
- Android UI implementation menggunakan Jetpack Compose
- Laporan hasil usability testing dengan actionable insights

# What I Learned

Belajar bahwa **desain yang baik harus bisa diimplementasikan**  dan implementasi yang baik harus menghormati intent desain. Gap antara keduanya sering jadi sumber konflik di tim, dan pengalaman ini memberi saya perspektif untuk menjembatani keduanya.
